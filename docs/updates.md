## 2026-11-02 — Production OS, resumable training and six Arena events / 生产系统、可续训训练包与六项 Arena 赛事

- Reviewed official stable daemon releases [v0.17.7](https://github.com/pollen-robotics/microduck/releases/tag/daemon-v0.17.7) through [v0.18.3](https://github.com/pollen-robotics/microduck/releases/tag/daemon-v0.18.3). They fix repeat provisioning, add network-pad mouth control and an endurance test, arm fall prediction only from standing, adapt camera frame rate on weak links, calibrate the beta GC2093 camera, reconnect bonded gamepads, shorten boot checks, and add optional vetbook sharing plus anonymous usage telemetry with a documented opt-out. Development builds and open pull requests were not treated as released behavior.
- Added the official [Microduck OS v1.1.0](https://github.com/pollen-robotics/microduck_yocto/releases/tag/microduck-os-v1.1.0). The production image now ships `padd` and `nfcd`, stores BlueZ bonds on the data partition across slot updates, filters the update page to installable builds, lowers its idle polling cost and verifies all twelve V1.0 face-board LEDs. The release explicitly says its new factory flashing guide and script have not yet been followed end to end on a board.
- Updated [Microduck RL](https://github.com/pollen-robotics/microduck_rl/commit/3b8759e9dad2bd12dae03129bc4a07fe24a48026) after it added opt-in training bundles. `share-training` can publish full `rsl_rl` checkpoints, exact provenance, teachers and ONNX hashes to a separate Hub repository; `hf://` checkpoint references support resume and compatible warm starts. The official [microduck-training](https://huggingface.co/pollen-robotics/microduck-training) repository now lists bundles behind several deployed policies. This improves reproducibility but is not a new hardware-performance claim.
- Updated [Arena v0.7.0](https://github.com/pollen-robotics/microduck-arena/releases/tag/v0.7.0) and [Microduck challenges](https://github.com/pollen-robotics/microduck-challenges/commit/5cee942d8b434aafd395070facb659034aac3b5e). v0.6 adds two-duck Tug of War, v0.6.1 handles a torn neck string as an entry fault/reset, and v0.7 adds the six-metre Sock Heist red-light/green-light event. Public training folders now cover six events with fixed checks and reference measurements; all results remain simulation competition evidence.
- Added [DuckBuddy](https://github.com/Animan-AI/DuckBuddy/commit/933c6d9547cfd0e5cd06c805bc406bf394ba6ca3) as `hardware-demo-reported`. It publishes the Orange Pi Zero 3W/HL-2915 boards, firmware, print project, actuator identification, training code and a physical-robot demonstration of offline spoken action sequences; the maintainer reports that configuration in daily use. The HD-1910 route, on-device VLM, localization and several attention/mission behaviors are explicitly still in progress or planned.
- Updated [Microduck replica](https://github.com/fanhao375/microduck-replica/releases/tag/microduck-software-v2026.10.31) for signed browser-delivered updates, local sit/stand voice control, model management, diagnostics and remappable controls. The release keeps the new gamepad driver, fresh-image combinations and Qinmo IMU path outside completed hardware acceptance. Updated [XGO Duck V1.1](https://github.com/LuwuDynamics/xgoduck_hardware/commit/7dd33c603cbff92bc4afbc7f318abd4ccd9127b6) for published manufacturing files and reverse-connection/stall videos, while retaining the missing V1.1 PCB source, absent compatibility notes and old-board wiring warning.
- Updated [quackd v0.29.1](https://github.com/rokbenko/quackd/releases/tag/v0.29.1) after reviewing its browser UI, multi-provider/local-model setup, Microduck head-watching reflex and simulated room exploration. The project still says `microduck:jsonrpc` is waiting for a physical Microduck and that exploration is not offered on real hardware, so `hardware-unverified` remains correct.
- Deferred the newly created `microduck-eyes` desktop renderer and Turkish build guide because they have no stable release and no reviewed physical-device result; deferred other very new simulator, VLA, observer and hardware repositories that still lack durable artifacts, clear licensing/provenance or reproducible evidence. Open runtime and RL pull requests, issue reports and development builds were reviewed as experimental work only, not cataloged as released capabilities.

本次核心更新：官方稳定 daemon 推进至 v0.18.3，生产系统 Microduck OS v1.1.0 首次纳入清单，手柄/NFC 服务、蓝牙配对保留、更新页面与面板 LED 验证均有一手发布证据，但工厂刷写流程仍未在板卡上完整走通。训练仓新增可选择发布的完整检查点与来源训练包，提升续训和热启动复现能力；Arena 新增拔河与 Sock Heist，公开训练工作坊扩展至六项仿真赛事。社区侧新增有实机语音连续动作演示的 DuckBuddy，更新 Microduck replica、XGO Duck 与 quackd，同时保留新驱动、镜像、IMU、PCB 资料和 Microduck 真机运行等未完成边界。刚创建、无稳定发布、缺少实物结果或来源/许可不清的候选继续暂缓。

## 2026-10-19 — v8 policies, Arena training and sustained replica walking / v8 策略、Arena 训练与复刻持续行走

- Reviewed official stable releases [v0.16.2](https://github.com/pollen-robotics/microduck/releases/tag/daemon-v0.16.2) through [v0.17.6](https://github.com/pollen-robotics/microduck/releases/tag/daemon-v0.17.6). The sequence moves shipped policies to v8, adds `duckctl` distribution and network-pad driving, rejects late or stalled pad input, makes axes and limits configurable, records each duck's lifetime vetbook, improves beta-board identity handling and changes updater discovery to use channel tags. The v0.17.5 and v0.17.6 notes explicitly say those builds were verified through the update engine in CI but not on a robot; `daemon-dev-prepare-release-0.17.7` remains a prerelease.
- Reviewed the official [v8 policy set](https://huggingface.co/pollen-robotics/microduck-policies/tree/v8) and [merged training lineage](https://github.com/pollen-robotics/microduck_rl/commit/b02fdea4902c2b93b7d34a83a6f05da4ececb7d3). The authors report real-robot validation of smoother, more reliable get-up, yaw-command tracking, turning and walking. This supersedes v7 as the shipped VelStand policy; it does not independently validate every v0.17 runtime change.
- Added the official [Microduck Arena v0.5.0](https://github.com/pollen-robotics/microduck-arena/releases/tag/v0.5.0) and [public challenge training repository](https://github.com/pollen-robotics/microduck-challenges/commit/6ff40704a1b086618b52173c4ea3851bb21ee4f6). The latter, which returned 404 during the previous review, now publishes complete folders for sprint, talent, hill-climb and roller-sprint events, local or Hugging Face Jobs workflows, checkpoint evaluation and publishing. Arena scores remain simulation measurements; v0.5.0's talent mode supports troupes of up to eight ducks with per-duck policies, placement, voice and song.
- Updated [Microduck replica](https://github.com/fanhao375/microduck-replica/commit/06822f1231f2f6a849b499708037c18b50c8ea97). After rejecting large BNO085 orientation jumps and integrating its gyro in a forked runtime, the maintainer reports 60 seconds of commanded walking without a fall and one fall over more than ten minutes in walk mode. No interleaved A/B test was completed; weak turning, occasional whole-board reboots and a non-default fork remain explicit limitations.
- Added [my-microduck-journal v0.2](https://github.com/xinhuagu/my-microduck-journal/releases/tag/v0.2), resolving the previous missing-artifact blocker. It now publishes default and fast VelStand ONNX files, teacher policies, raw multi-seed evaluation JSON, checksums, patches and exact training scripts. The reported speed, recovery and goal results are reproducible simulation claims from the maintainer, not independent evaluation or hardware validation.
- Added [Microduck-kissqy](https://github.com/kissqy/Microduck-kissqy/commit/f02e875e73b88bf8ec7d5bbb34d0b461ac83b010), resolving its previous upcoming-only status. It now publishes a flash-tested R1 system image, V167 control console, training console, firmware source and binaries, HAT/IMU files, a complete print set and author hardware videos. Per-robot calibration is still required; motion quality depends on assembly and training, and the author's original additions use personal non-commercial terms while upstream components retain their own licenses.
- Updated [quackd v0.18.0](https://github.com/rokbenko/quackd/releases/tag/v0.18.0) and [v0.18.1](https://github.com/rokbenko/quackd/releases/tag/v0.18.1). They refresh the Microduck adapter for robotd API 23 and later, document stable releases through v0.17.6 and tighten posture, move-echo and camera behavior. The maintainer explicitly states that no Microduck has run quackd yet, so `hardware-unverified` remains unchanged.
- Rechecked the XGO Duck assembly-guide update, the official Arena submissions on the Hub and newly active GitHub repositories. Individual leaderboard policies were not added because an uploaded model or score is not by itself a durable user route; very new observer, calibration, voice, VLA, simulator and hardware repositories were deferred when they lacked a stable release, complete reproducibility evidence, clear provenance/licensing or enough history to distinguish a maintained project from a one-off upload.

本次核心更新：官方稳定运行时推进至 v0.17.6，但 v0.17.5–v0.17.6 明确仅通过 CI 更新验证、未经真机验证；官方 v8 VelStand 已由作者报告在真机验证更平顺可靠的起身、偏航跟踪、转向与行走。此前不可访问的官方 Arena 挑战仓现已公开，形成四项可复现仿真赛事和发布流程。社区侧，HD-1910 复刻在 BNO085 陀螺融合修复后首次报告持续行走，但仍缺交错 A/B 且存在弱转向和偶发重启；my-microduck-journal 已补齐 ONNX、原始评测与校验和，Microduck-kissqy 已补齐镜像、固件、中控、打印件与实机演示，因而解除上次暂缓。quackd 已跟进当前 robotd，但仍未在 Microduck 真机运行。单个 Arena 投稿、刚创建项目及缺少稳定证据或明确许可的候选继续暂缓收录。

本次核心更新：官方稳定运行时升至 v0.16.1，补齐 beta 板传感器、摄像头、灯效与手柄断连安全行为；官方训练仓明确 STL 网格采用 CC BY-NC-SA 4.0，其余列明文件保持 Apache-2.0。ROS 2 路线已对齐 v7 策略但仍无真机驱动；HD-1910 复刻已在实体机上跑通 BNO085、15 舵机控制环、HOME 与 10 秒策略保持，连续行走仍因过热降频未验证。新增 Jetson Orin Nano 外置算力挂载方案，但仅按仿真结果标注。缺少公开权重、尚未发布新版、未发版兼容修订或复现仓仍不可访问的候选继续暂缓收录。
